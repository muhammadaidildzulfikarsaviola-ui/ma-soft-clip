4. CMAKE FORMAT CONFIGURATION
============================================================

Default formats:

    VST3
    Standalone

VST2:

    BUILD_VST2 OFF

When VST2 is enabled:

    juce_set_vst2_sdk_path("${VST2_SDK_PATH}")

and:

    VST

is appended to the plugin formats.

Example configuration:

    set(BUILD_VST2 OFF)

    set(PLUGIN_FORMATS
        VST3
        Standalone
    )

    if(BUILD_VST2)
        juce_set_vst2_sdk_path("${VST2_SDK_PATH}")
        list(APPEND PLUGIN_FORMATS VST)
    endif()

============================================================
6. DSP ARCHITECTURE
============================================================

Audio processing path:

    INPUT
      |
      v
    Input Meter
      |
      v
    Input Gain
      |
      v
    Oversampling
      |
      v
    Soft Clip
      |
      +----> Gain Reduction calculation
      |
      +----> Waveform data
      |
      v
    Clipper
      |
      v
    Output Gain
      |
      v
    Downsampling
      |
      v
    Output Meter
      |
      v
    OUTPUT


Important:

- Audio processing runs on the audio thread.
- GUI must NOT process audio.
- GUI must NOT call repaint() from the audio thread.
- GUI must NOT perform unsafe memory allocation in processBlock().
- GUI reads monitoring data through safe shared state / atomics / FIFO.

============================================================
10. METER SYSTEM
============================================================

Input:

    RMS
    Peak

Gain Reduction:

    Current GR
    Peak GR

Output:

    RMS
    Peak

Analog meter behavior:

    RMS -> main needle

    Peak -> peak-hold needle

Peak hold:

    - immediate attack
    - smooth decay

Meter visuals should follow the approved hardware-inspired
reference design.


============================================================
11. WAVEFORM MONITOR
============================================================

Realtime waveform monitoring must represent actual audio data.

Possible visualization:

    INPUT
    waveform

    OUTPUT
    waveform

or a combined processing visualization.

Threshold visualization:

    threshold line

The threshold line moves with the Threshold parameter.

Waveform data comes from the actual audio processing path.


============================================================
12. TRANSFER CURVE
============================================================

Realtime transfer curve.

Axes:

    X = Input
    Y = Output

The curve changes when:

    Threshold changes
    Knee changes
    Clip Style changes
    Processing mode changes

Concept:

    Soft:
        smooth transition into clipping

    Medium:
        stronger transition

    Hard:
        sharper clipping behavior
